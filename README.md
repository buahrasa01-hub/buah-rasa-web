# Buah Rasa — Website

Landing page sederhana untuk **Buah Rasa**: belajar bikin sesuatu dari nol — game, website, dan video — lalu membagikan caranya lewat tutorial.

Website ini dibuat mengikuti tutorial di channel YouTube **Bu Ah** (@buah2891):
**“Cara Bikin Website Gratis (GitHub Pages + Vercel)”**.

## Live

- GitHub Pages: https://buahrasa01-hub.github.io/buah-rasa-web/
- Vercel: (lihat deskripsi video — ditambahkan setelah deploy)

## Isi

| File | Fungsi |
| --- | --- |
| `index.html` | Struktur halaman: hero, proyek, tentang, kontak |
| `style.css` | Tampilan: warna, kartu, mode gelap, responsif HP |
| `script.js` | Interaksi: mode gelap, penghitung bintang, tahun footer |

Tanpa library, tanpa server, tanpa build step. Buka `index.html` di browser, langsung jalan.

## Cara memakai

1. Fork repo ini, atau unduh sebagai ZIP.
2. Ubah teks di `index.html` menjadi punyamu.
3. Ubah warna di `:root` pada `style.css`.
4. Push ke GitHub, aktifkan Pages — websitemu langsung online.
